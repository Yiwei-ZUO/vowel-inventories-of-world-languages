# Vowel Inventories of World Languages

This repository contains the code and data for **Lab 1: A Statistical Analysis of Vowel Inventories of World Languages** for the Multilingual NLP course at Université Paris Cité.

## Project

This project uses **PHOIBLE v2.0** to investigate cross-linguistic patterns in vowel inventories, with a focus on two proposed linguistic universals:

1. whether languages generally contain the basic vowel triangle /i, a, u/ or close equivalents;
2. whether highly marked vowels tend to imply corresponding simpler vowels.

The analysis also explores vowel co-occurrence patterns and the effect of genealogical non-independence.

## Files

- `m2_lab1_zuo_code.ipynb` — complete Python code and outputs
- `phoible.csv` — PHOIBLE data
- `languages.csv` — language family and macroarea metadata
- `frequent_vowel_pairs.csv` — frequent vowel pairs identified in the analysis
